Native KT implementation additions retain upstream notices: `worker_pool.cpp` sparse-NUMA counters, `loader.py` exact UE8M0 correction, additive AVX2 native1017 phases/pybind bindings, and SGLang native-cache hooks. The lossless GGUF adapter reuses KT/gguf metadata reading and llama.cpp packing definitions. Native SM89 writes reuse the validated Strata cache quantizer and sparse-attention primitive, with DeepSeek released rounding rules; the integration does not claim upstream full-model numerical parity. Exact pins and modifications are recorded in `completion_work/kt_engine_decision/*_results/`.

The subsequent native engine integration also retains KT ownership of loader factories, task queues and NUMA execution, with a narrow physical-node memory-policy correction. SGLang owns model completion, linear loaders, metadata and attention interfaces; the native adapter adds explicit released-format policies and qualified SM89 paths. DeepSeek defines the original checkpoint and quantization contracts. Reports distinguish fixture ports and independently measured adaptations from upstream guarantees.

The runtime-epsilon fix forwards SGLang’s existing public quantizer parameter through its existing CUDA/JIT implementation, preserving the default and avoiding a second quantization backend. Native index dummy-slot filtering and finite-status checks also reuse the existing scatter/scoring kernels. DeepSeek’s original numerical boundaries and independently retained fixtures define qualification; successful component tests are not upstream full-model guarantees.
